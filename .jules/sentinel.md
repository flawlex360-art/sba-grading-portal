## 2026-07-30 - Client-Side Administrator Registration Backdoor
**Vulnerability:** The login component (`Login.jsx`) included a check to query if any admin user document exists in Firestore. If not found or if the check failed, the application displayed a client-side backdoor button to register `admin@school.com` with whatever password the user entered, setting `isAdmin: true`. This would allow any unauthorized user visiting the site to register as the administrator on a fresh database, or during temporary connectivity/permission glitches.
**Learning:** This arose because the application allowed a dual provisioning path for administrators: a secure server-side/CLI CLI script (`register_admin.js`), and a fallback client-side helper path in the login screen. Leaving administrative provisioning features in the client-side code exposes a high-severity backdoor.
**Prevention:** Remove administrative account creation logic from client-side views. All admin accounts must be provisioned out-of-band via secure command-line interfaces or authorized cloud consoles (e.g. Firebase Console or CLI script).
